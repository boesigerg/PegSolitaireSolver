This project is meant, first and foremost, as an excuse to try and learn some golang.

The idea is to write a program that tries to play every possible game of Peg Solitaire (The game you can play at Cracker Barrel while waiting for food) and returns the result.
I remember a similar game on old Windows versions with a similar, if not exactly the same, concept.

As I write this, the goal is simply to "solve" the standard triangle layout with side length=5 and spit out the number of possible games (Excluding mirrored moves is a bonus) and how many pegs are left for each game.

I may expand further and look at different shapes/configurations for the board, potentially seeing if there are any fun patterns to be found.
